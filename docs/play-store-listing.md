## App name

## Short description

## Full description

MathVerse is an offline study companion for students preparing for mathematics and Class 12 physics exams.

Find the formula you need quickly, practise active recall with flashcards, work through step-by-step examples, and keep your own revision notes in one focused study space.

### Study smarter with MathVerse

- Browse mathematics and Class 12 physics formulas by subject, level, topic, or search term.
- Save important formulas for quick revision.
- Test yourself with active-recall flashcards and a bonus review mode.
- Explore worked examples and use interactive solvers for quadratics, linear equations, triangles, and radicals.
- Convert common units and use square/cube-root reference tables.
- Write, pin, search, edit, and copy your own exam notes.
- Download formula sheets for revision.
- Use core study features offline.

MathVerse is built to help students revise with less searching and fewer distractions.
